# 要求仕様

## 概要
資格勉強の実績(勉強時間・やったこと・メモ)をスマートフォンから手軽に記録し、資格ごとの進捗を振り返れる個人用アプリ。

## 想定利用者
- 本人のみが使用する個人用アプリ
- 主な利用端末はスマートフォン(レスポンシブ対応)

## 用語
| 用語 | 意味 |
|---|---|
| 資格 | 勉強対象の資格・試験(例: AWS SAP、情報処理安全確保支援士) |
| 学習記録 | 1回の勉強に対する記録(日時、時間、やったこと、メモ) |
| マイルストーン | 資格ごとに設定する目標・中間目標 |

## 機能要件

### 1. 資格の管理
- 資格を登録・編集できる
- 登録例: GitHub Copilot、GitHub Actions、AWS ソリューションアーキテクトプロフェッショナル、情報処理安全確保支援士
- 資格ごとに名称・識別用の色を持つ(カレンダーの色分けに使用、色は 10 色のプリセットパレットから選択)
- 資格ごとに略称(任意)を持てる(例: GitHub Copilot → GH-300)。カレンダーの凡例やチップなど表示スペースが狭い箇所では、略称があれば略称を優先して表示する
- 資格には「学習中」「クローズ」の状態を持つ
  - クローズにすると、新規の学習記録入力時の選択肢からは外れるが、資格一覧・資格詳細・カレンダーでは引き続き参照できる(振り返り用)
- 資格の削除は、紐づく学習記録・メモ・マイルストーンを含めて完全にデータを削除する操作とする(元に戻せないため、削除前に確認を行う)

### 2. 学習記録の登録・編集・削除
- 1回の勉強(セッション)ごとに記録を追加する方式とし、同じ日に同じ資格を複数回記録できる(例: 同日に GitHub Copilot を2回、GitHub Actions を1回など)
- 資格を選択し、以下を記録する
  - 日付
  - 勉強時間(単位: 時間(H)。0.25H 刻みの小数入力。例: 0.5, 1.0, 1.5)
  - やったこと(テキスト)
  - メモ(テキスト、任意)
- スマホから素早く入力できる UI(直近使った資格をチップで上位表示、時間は 0.25H 刻みのステッパー/数値入力)
- タイマー機能は持たない
- 登録済みの学習記録は、後から編集・削除できる(入力ミスの訂正のため)

### 3. 資格ごとの集計・振り返り
- 資格ごとに合計勉強時間を表示する(同日複数セッションも合算)
- 資格ごとに過去のメモ・学習記録を一覧で見返せる

### 4. カレンダー表示
- カレンダー上で、日付ごとにどの資格を何をやったか分かる
- 各日付のセルに、その日勉強した資格の色(ドット or バー)を表示し、一目で資格を判別できるようにする
- 同じ日に複数の資格を勉強した場合、その日のセルにそれぞれの資格の色を並べて表示する(例: GitHub Copilot色 + GitHub Actions色)
- 日付をタップすると、その日の学習記録をセッション単位の時系列リストで表示する(資格・時間・やったこと・メモ)

### 5. マイルストーン管理
- 資格ごとに複数のマイルストーンを設定できる
- マイルストーンには目標(タイトル)と期限(任意)を持たせる
- 達成/未達成を管理できる
- 期限を超過して未達成のマイルストーンは、アプリ内(資格一覧・資格詳細画面など)でバッジや強調表示により通知する(プッシュ通知・メール通知は行わない)

### 6. 認証
- ログインは 8 桁の数字(PIN コード)のみ
- 個人用アプリのため、ユーザー登録・メールアドレス等は不要
- PIN は 1 つのみ(マルチユーザー非対応)
- PIN は `.env`(環境変数)で管理し、コードにハードコードしない
- ログイン後のセッション有効期限は 12 時間とし、超過後は再度 PIN 入力を求める
- PIN を 5 回連続で間違えた場合、5 分間ログイン試行をロックする(総当たり対策)
- PIN の変更はアプリ内からは行わない(インフラ側で環境変数を更新して対応)

## 非機能要件
- スマートフォンでの利用を最優先としたレスポンシブデザイン
- CLAUDE.md のインフラ構成(S3 + CloudFront / API Gateway + Lambda + DynamoDB)に準拠
- データは DynamoDB に保存するため、アプリ側でのバックアップ・エクスポート機能は持たない

## 画面構成(想定)
| 画面 | 内容 |
|---|---|
| ログイン | 8桁 PIN 入力 |
| ホーム/カレンダー | 月表示カレンダー、日付セルに資格ごとの色ドット/バー、タップで当日のセッション一覧を表示 |
| 資格一覧 | 資格ごとの合計勉強時間、マイルストーン達成状況(学習中/クローズを区別して表示) |
| 資格詳細 | 学習記録一覧(編集・削除可)、メモ一覧、マイルストーン一覧 |
| 学習記録入力 | 資格選択、時間、やったこと、メモの入力フォーム(新規登録・編集を兼ねる) |
| マイルストーン管理 | マイルストーンの追加・編集・達成管理 |

## データモデル(概要)
- 資格(Qualification): id, name, abbreviation(任意), color(プリセットパレットから選択), status(open / close)
- 学習記録(StudyLog): id, qualificationId, date, createdAt(同日複数セッションの並び順用), hours, content, memo
- マイルストーン(Milestone): id, qualificationId, title, plannedDate(任意), completedDate(任意), status(open / close)

## 対象外(Non-goals)
- マルチユーザー対応(PIN は 1 つのみ、ユーザー登録なし)
- 勉強時間のタイマー機能
- プッシュ通知・メール通知(マイルストーン期限超過はアプリ内表示のみ)
- データのバックアップ・エクスポート機能(DynamoDB の永続性に依存)
- 資格の色の自由指定(10 色のプリセットパレットのみ)
